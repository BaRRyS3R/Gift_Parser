# Техническая документация проекта PvP Game

## 1. Общее описание проекта

Проект представляет собой многопользовательскую карточную игру с элементами PvP, реализованную с использованием современного стека технологий. Проект использует Next.js для фронтенда, Express.js и Socket.IO для бэкенда, и Supabase в качестве базы данных.

### 1.1 Игровая концепция

- Карточная игра в жанре коллекционной карточной игры (CCG)
- PvP формат с системой рейтинга
- Система колод и коллекций карт
- Экономика внутриигровой валюты
- Система прогресса и достижений

### 1.2 Целевая аудитория

- Игроки карточных игр
- Поклонники PvP соревнований
- Коллекционеры карт
- Казуальные игроки
